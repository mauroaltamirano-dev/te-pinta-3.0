# Installation identity

Objective: make one codebase serve separate installations (Te Pinta and a rented POS client with its own database, domain and admin) by moving restaurant-specific identity out of code. Branch `feat/installation-identity` from `main` at `a873319`. Delivery: ask-on-risk; local branch only, no push or PR without the user's OK. Test runner: PHPUnit through Sail (`vendor/bin/sail artisan test`), Playwright for e2e.

## Specs

- S1 — Same code, never a fork: "Debe ser el mismo código, configurable para ambos, nunca un fork." Te Pinta's rendered output must not change.
- S2 — Restaurant identity texts (stage 1 of the plan, authorized with "Claro"): name, home eyebrow, headline with an optional highlighted fragment, intro, home page title, up to three highlights (home strip and footer "Cómo pedir"), footer blurb, location, coming-soon text and empty-cart text are stored per restaurant, editable in Configuración → General by the same permission as the accent color (`catalog.manage`), and every user-visible "Te Pinta" literal in pages, layouts, meta tags and product SEO reads them. Te Pinta's current strings are migrated as its values.
- S3 — Brand images per installation (wordmark/mark, badge, favicon, hero, menu background, PWA icons and manifest). Pending: not started; needs its own design (uploads, public gateway allowlist).
- S4 — Order public ID prefix per installation (`TP-` is a column DEFAULT today). Pending: high-risk item 1 (persisted format); own commit and independent verifier.
- S5 — Future stage, recorded verbatim, not authorized for implementation yet (L2): quantity-based sale types per product, combos on the web, toggleable promotions such as "Docena Surtida" at a fixed price, combo products with their own price and stock. See L2. Decision L3: "Docena Surtida" is a staff-applied promo, separate from the combined dozen: "en la docena combinada el cliente elije las variedades, por eso es distinto el precio, la docena combinada por defecto es siempre la misma, pero si marcamos docena surtida, ahí se cambia el precio al fijo y no al combinado".

Assumptions:
- A1 — Highlight icons stay fixed per position (flame, bike, message); only their text is configurable.
- A2 — A null text hides that piece or uses a neutral fallback; only the restaurant seeded as `te-pinta` receives Te Pinta's strings.
