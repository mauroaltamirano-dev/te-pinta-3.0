Branch `feat/public-coming-soon` chained on `feat/brand-logos` (`6c0b572`); later tasks on their own branches. Delivery: local branches only; push, merge and deploy only with the user's OK. Test runners: PHPUnit in `sail-8.5/app` against the private Postgres `tepinta-print-e2e-pg` (127.0.0.1:55520), Playwright chromium/mobile-chromium.

- S8 — "en el precio por docena, poner la típica de $20.000 (al lado el precio de docena original tachado y en grís) % descuento, o sea, hacer la promo visible de cuánto sale la docena de una variedad con su descuento respectivo (siendo el precio de 12 unidades sin el precio fijo de docena el "anterior" o de no ahorro)". Public dozen price shows D, next to it 12 × U struck through in gray, and the discount percentage.
- S9 — "en la web pública, quisiera que el menú, las cards de los productos se vean chicos, ocupan mucha pantalla en desktop". Compact menu cards: four columns from `xl`, tighter padding and type; unit and half-dozen prices on one line under the dozen price.
- S10 — "Horario de pedidos: hoy la web acepta pedidos 24/7; debe aceptarlos solo dentro de un horario configurable desde Configuración (bloqueante de lanzamiento)." Shape (user: "de momento lo nuestro es de lunes a lunes, y el horario de atención es de 19hs a 00hs"): one window per weekday (opening and closing time, or closed), editable in Configuración; a closing time at or before the opening time ends the next day. Seed: every day 19:00–00:00. Outside the window the menu and cart stay usable, checkout shows when ordering opens, and the backend rejects the order.
- S11 — "saquemos la opción de que el cliente elija el horario, eso se coordina por mensaje cuando el cliente haga el pedido" + chosen option "Horario + sin fecha": public checkout no longer asks for date, period or time; the order is for the current opening window. Assumption: the server stores the window's start date as `delivery_date` and derives `delivery_period` from the window's opening time (before 15:00 midday, before 19:00 afternoon, otherwise night), `delivery_time` null.
- S12 — "Aviso en el admin cuando entra un pedido web nuevo (alerta o refresco automático)."
- S13 — "Encabezados de seguridad en tepinta.com.ar (HSTS, CSP, X-Frame-Options, nosniff, Referrer-Policy)."
- S14 — "Cerrar el remodel y dejarlo listo para mergear a main (T4 de fotos reales queda esperando mis fotos)." Merge, deploy and opening the site (`PUBLIC_SITE_OPEN`) only after asking the user.
- S7 — "sobreotdo porque quiero sacar y usar fotos reales, y todavía no las tengo". Real photos replace placeholders when the user provides them (external dependency).
